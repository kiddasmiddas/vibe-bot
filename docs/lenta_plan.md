## Часть 1. Согласованные решения

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Где создавать пост | **В Mini App.** Бот — только уведомления и навигация в раздел «Лента». |
| 2 | Модерация | **Постмодерация + автопроверка** (ссылки, NSFW). Опционально: первые 1–3 поста нового автора → ручная проверка. |
| 3 | Комментарии/реакции | **В Mini App.** Бот шлёт уведомления автору («ваш пост прокомментировали / получил реакцию»). |
| 4 | Кружки в вебе | Заглушка-превью + кнопка «Открыть в Telegram». |
| 5 | Реакции | **4 типа: 💚 ✨ 😭 👀.** Одна реакция на пользователя на пост; выбор другой — заменяет прежнюю. Без мультивыбора. |
| 6 | Лимиты | Обычный: постов нельзя, 30 комм/день. Premium: 50 постов/мес, 100 комм/день. В `app_settings` заложить запас до 100 постов / 300 комм. |
| 7 | Медиа в комментах (Premium) | Комментарий — **либо текст, либо медиа** (не одновременно). У обычного — только текст. |
| 8 | Анкета для доступа | Без анкеты — **превью** ленты (ограниченное число постов) + предложение заполнить. Реакции / комментарии / полный просмотр — только с анкетой. Постинг — анкета + активный Premium. |

## Часть 2. Архитектура

Лента **технически отделена** от «Аллеи креаторов» (свои таблицы, свои
API-роуты), переиспользует каркас Mini App, модерацию, шедулер, админку.

### 2.1. Модели БД (новые таблицы)

**`feed_posts`**
- `id`, `author_user_id` → users
- `text`
- `status`: `active` / `expired` / `hidden_by_moderator` / `deleted_by_user` / `blocked`
- `is_pending_review` (bool) — для опц. ручной проверки первых постов автора
- `created_at`, `published_at`, `expires_at` (`published_at + 48ч`), `purge_at` (`expires_at + 4д`)

**`feed_post_media`**
- `id`, `post_id` → feed_posts, `media_type` (`photo`/`gif`/`video`/`video_note`),
  `file_id`, `position`

**`feed_comments`**
- `id`, `post_id` → feed_posts, `author_user_id` → users
- `text` (nullable), `media_type` (nullable), `media_file_id` (nullable)
- CHECK: заполнено `text` XOR (`media_type` + `media_file_id`) — комментарий
  либо текст, либо медиа
- `status`: `active` / `deleted_by_user` / `deleted_by_moderator`
- `created_at`

**`feed_reactions`**
- `post_id` → feed_posts, `user_id` → users, `reaction_type` (`heart`/`sparkle`/`cry`/`eyes`)
- PK `(post_id, user_id)` — одна реакция на пользователя; смена = upsert

**`feed_comment_restrictions`**
- `user_id` → users, `until` (datetime), `created_by_admin_id`
- Ограничение пользователя в комментариях модератором

### 2.2. Настройки (`app_settings`, меняются без деплоя)

| Ключ | Дефолт | Запас |
|------|--------|-------|
| `feed_post_limit_premium_month` | 50 | до 100 |
| `feed_comment_limit_regular_day` | 30 | — |
| `feed_comment_limit_premium_day` | 100 | до 300 |
| `feed_post_ttl_hours` | 48 | — |
| `feed_post_purge_days` | 4 | — |
| `feed_preview_limit_no_profile` | 10 | — |
| `feed_premoderate_first_n_posts` | 3 (0 = выкл) | — |

### 2.3. API (FastAPI, новые роуты `/api/feed/...`)

**Чтение:**
- `GET /api/feed/posts?cursor=&limit=` — лента `active`, курсорная пагинация.
  Без анкеты — максимум `feed_preview_limit_no_profile` постов.
- `GET /api/feed/posts/{id}` — пост + реакции (счётчики) + моя реакция
- `GET /api/feed/posts/{id}/comments?cursor=` — комментарии

**Запись (новое — мутации из Mini App):**
- `POST /api/feed/posts` — создать (Premium + анкета; лимит; автопроверка
  ссылок и NSFW; первые N постов → `is_pending_review`)
- `POST /api/feed/posts/{id}/comments` — комментарий (анкета; лимит;
  автопроверка ссылок; медиа XOR текст)
- `PUT /api/feed/posts/{id}/reaction` — поставить/сменить реакцию (анкета)
- `DELETE /api/feed/posts/{id}/reaction` — снять свою реакцию
- `DELETE /api/feed/comments/{id}` — удалить свой комментарий
- `POST /api/feed/posts/{id}/report`, `POST /api/feed/comments/{id}/report` — жалоба

**Доступ-гейтинг** (зависимость в `deps.py`):
- `current_user` — как сейчас
- `current_user_with_profile` — 403, если анкета не заполнена (для реакций/комментов)
- `current_premium_user_with_profile` — для постинга

⚠️ Write-эндпоинты требуют **API-level rate limiting** (Redis) — сейчас антиспам
только в боте, для API его нет. Добавляем в Этапе Л3.

### 2.4. Уведомления в бот

Сервис `feed_notification_service`: при новом комментарии/реакции — `bot.send_message`
автору поста («Ваш пост прокомментировали» / «получил реакцию»). Батчинг/дедуп,
чтобы не спамить при всплеске активности (агрегировать, напр. «5 новых реакций»).

### 2.5. Mini App (раздел в существующем `webapp/`)

- Страница ленты — карточки, бесконечный скролл
- Карточка поста — медиа, текст, реакции (счётчики), число комментариев
- Экран поста — комментарии + форма комментария + панель реакций
- Форма создания поста (Premium) — текст + загрузка медиа
- Баннер «заполни анкету» для гостей без профиля

### 2.6. Шедулер (APScheduler — расширяем)

- `feed_expiry` — `active → expired` при `expires_at < now()` (каждые ~10 мин)
- `feed_purge` — физическое удаление при `purge_at < now()` (раз в сутки)

### 2.7. Модерация — раздел «Лента» в `/admin`

Список постов с фильтром по статусу; скрыть/удалить пост; удалить комментарий;
забанить автора; ограничить в комментариях (`feed_comment_restrictions`); очередь
жалоб; очередь `is_pending_review` (первые посты новых авторов); лог скрытых/удалённых.

### 2.8. Запрет ссылок

Переиспользуем `content_moderation_service` (regex на ссылки/@mentions уже есть).
Проверка текста постов и комментариев. Запрещённая ссылка → публикация
отклоняется + предупреждение пользователю.

## Часть 3. Под-этапы

| Под-этап | Содержание |
|----------|-----------|
| **Л1** | Модели + миграция `feed_*` + репозитории + seed настроек |
| **Л2** | API чтения (посты, пост, комментарии) + доступ-гейтинг по анкете |
| **Л3** | API записи (посты/комментарии/реакции/жалобы) + лимиты + автопроверка ссылок/NSFW + API rate limiting |
| **Л4** | Mini App: лента + экран поста + комментарии + реакции |
| **Л5** | Mini App: форма создания поста (Premium) + загрузка медиа |
| **Л6** | Шедулер (expiry + purge) + раздел «Лента» в админке |
| **Л7** | Уведомления в бот + кнопка «Лента» в меню + сквозные тесты + smoke |

Каждый под-этап завершается тестами + `ruff` + smoke. Объём ≈ как «Аллея».

## Часть 4. Открытые мелочи (решим по ходу, не блокируют старт)

- Премодерация первых N постов автора — реализуем флагом `feed_premoderate_first_n_posts`
  (0 = выкл), включить можно позже. Заказчик пометил «если не усложнит» — заложим
  поле, включение опционально.
- Дедуп уведомлений (агрегация «N реакций») — детали на Л7.
- Гостевое превью без анкеты: показываем N постов, детали поста — тоже превью
  или сразу требовать анкету? Уточнить на Л2.
